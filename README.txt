LOPHERA STORE — protótipo V1

Arquivos:
- index.html = página inicial
- loja.html = catálogo
- sobre.html = página institucional
- admin.html = painel de edição local
- assets/products.json = catálogo importado da base da Lophera
- assets/logo.svg / hero.svg = identidade visual inicial

COMO TESTAR:
1. Extraia a pasta.
2. Abra index.html em um navegador.
3. Abra admin.html para testar a edição de produtos.
4. As alterações do painel são salvas no navegador por localStorage.

IMPORTANTE:
Esta é uma primeira versão funcional/protótipo. O checkout, pagamento, cálculo real de frete, autenticação do painel e banco de dados ainda precisam ser conectados antes da publicação em lophera.com.br.
